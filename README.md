# Online Book Store Analysis Using SQL

## Project Overview
This project analyzes an online bookstore database using SQL to explore books, customers, inventory, and order transactions.

## Dataset
The project contains three datasets:
- **Books:** Book titles, authors, genres, prices, publication years, and stock.
- **Customers:** Customer information and geographical details.
- **Orders:** Order dates, quantities, customer IDs, book IDs, and total amounts.

## Tools Used
- SQL
- Relational database concepts
- CSV datasets

## SQL Concepts Practiced
- SELECT, WHERE, and ORDER BY
- Aggregate functions such as SUM, MAX, and MIN
- GROUP BY and HAVING
- Subqueries
- Filtering and data analysis

## Business Questions
1. Which books belong to the Fiction genre?
2. Which books were published after 1950?
3. What is the total available stock?
4. Which book has the highest price?
5. Which orders exceed $20?
6. What is the total revenue from orders?
7. Which books have the lowest stock?

## Project Files
- `Online_Book_Store.sql` — SQL analysis queries.
- `Books.csv` — Book dataset.
- `Customers.csv` — Customer dataset.
- `Orders.csv` — Order dataset.

## How to Run
1. Import the CSV datasets into your database.
2. Create the required tables with appropriate column names and data types.
3. Execute `Online_Book_Store.sql` in your SQL editor.
4. Review the query results to answer the business questions.
